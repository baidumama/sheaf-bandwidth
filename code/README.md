# code/

Numerical reproducibility scripts for the paper.

All scripts depend on `numpy` only (Python 3.10+). Optional dependencies for the `B3*` simulation suite: `scipy`, `matplotlib` (see `requirements.txt` in the public mirror; locally a `.venv` is used).

## Reproducing the verification

The most important script for paper §7 is `A_route_ch3_numerical.py`:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install numpy
python3 A_route_ch3_numerical.py
```

Expected output: three instances of `sheafBW = σ_min / σ_max` with `reldiff ≤ 1.64 × 10^-14` (Instance 2; Instances 1 and 3 within `8 × 10^-16`). The deviation in Instance 2 reflects the squaring of the condition number under the $A^* A$ form and is well within the floating-point error budget; the strict equality of `thm:strict-equality` holds in all three constructions.

## Running B3 simulations

```bash
source .venv/bin/activate
python3 B3pre_hodge_separating.py        # ~3 s; writes results.json + 20 figures
python3 B3_stage1.py                     # stage 1
python3 B3_stage2_prep.py                # stage 2 prep, single N
python3 B3_stage2_prep_multi_N.py        # stage 2 prep, multi N stratification
python3 B3_main_simulation.py            # full simulation; longest runtime
```

All scripts use deterministic fixed seeds for reproducibility (seed values documented inside each script).

## Notes

- Path handling uses `Path(__file__).resolve().parent`, so scripts run correctly from any working directory.
- Scripts write `*.json` and `figures/*.png` into the script directory.
- The `B3*` numerical results are project-internal evidence supporting paper §6 (and are not the primary verification of `thm:strict-equality` — that is `A_route_ch3_numerical.py` for paper §7).
